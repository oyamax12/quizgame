🤖 إعدادات الذكاء الاصطناعي

يتم استدعاء نموذج الذكاء الاصطناعي مباشرة من متصفحك، وهذا مناسب للاستخدام الشخصي فقط. عند نشر اللعبة للعموم يُنصح بتمرير الطلبات عبر خادم خاص بك حتى لا يظهر مفتاحك في المتصفح.

وضع Puter يستخدم نفس نماذج Gemini الحديثة مجانًا بدون أي API Key. عند أول استخدام قد يظهر لك مربّع تسجيل دخول بسيط من Puter (مجاني) لضمان استمرار الخدمة مجانًا.

🟡 لم تتم إضافة API Key

🌐 خادم اللعب الجماعي

اللعب مع الأصدقاء وOnline 1v1 يحتاجان خادمًا منفصلاً (Node.js) لا يمكن لـ GitHub Pages استضافته. شغّل الخادم الموجود في مجلد /server على أي استضافة تدعم Node (مثل Render أو Railway)، وألصق رابطه هنا (مثال: wss://my-server.onrender.com).
