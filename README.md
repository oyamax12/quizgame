# فيصل — لعبة الأسئلة الذكية

لعبة تريفيا تعتمد على الذكاء الاصطناعي، مبنية بـ HTML5 + CSS3 + JavaScript ES6+ فقط
(بدون React/Vue/Angular/TypeScript)، بواجهة عربية RTL وتصميم متجاوب Mobile First.

## ما تم بناؤه الآن (كل المراحل 1-6)

- الصفحة الرئيسية + التنقل بين الشاشات.
- الإعدادات: مزوّدان للذكاء الاصطناعي — **Puter (بدون مفتاح، مجاني، افتراضي)** أو **مفتاح Gemini الخاص بك**، اختيار/كتابة Model، زر اختبار الاتصال، شارة حالة الاتصال 🟢🔴🟡، إعدادات اللعبة العامة، الوضع الداكن/الفاتح، الصوت، ورابط خادم اللعب الجماعي.
- **Demo Mode** تلقائي عند تعذّر الوصول للذكاء الاصطناعي، ببنك أسئلة محلي.
- لعب فردي كامل: تصنيف/صعوبة (أو تلقائي)/عدد أسئلة/مدة السؤال، أسئلة AI مع تحقق صارم من JSON وإعادة محاولة تلقائية، مؤقت، نقاط مع مكافأة سرعة وسلسلة وأنواع جولات، Power-Ups، وضع Chaos/Madness، نتائج وXP ومستويات وإنجازات وملف شخصي.
- **لعب مع الأصدقاء (Rooms، 2-8 لاعبين)** وOnline 1v1: إنشاء/انضمام برمز غرفة، شاشة انتظار بحالة الجاهزية، بدء تلقائي عند استعداد الجميع، أسئلة متزامنة، والنقاط/الوقت محسوبة على الخادم حصرًا لمنع الغش.
- **المتصدرون العالميون**: يُجلَبون من خادم اللعب الجماعي بعد كل مباراة منتهية.
- خادم Node.js حقيقي في `/server` (WebSocket + HTTP) — راجع `server/README.md` للنشر خطوة بخطوة، لأن GitHub Pages لا يستضيف الخوادم.
- كل شيء محفوظ في `localStorage` (أو على الخادم لبيانات اللعب الجماعي) — لا يوجد أي API Key مكتوب داخل الكود.

## ملاحظة أمان مهمة

هذا الإصدار يتصل بالـ AI API مباشرة من المتصفح (`Frontend → AI API`)، وهو
مناسب للاستخدام **الشخصي** فقط لأن أي شخص يفتح أدوات المطوّر يرى المفتاح.
عند النشر للعموم، أضف خادمًا وسيطًا (`Frontend → Backend → AI API`) بحيث
يبقى الـ API Key على الخادم فقط. طبقة `AIService` مصممة بحيث لا يحتاج بقية
الكود لأي تعديل عند إجراء هذا الانتقال — فقط عدّل دالة `callModel()`.

## هيكل الملفات

```
/index.html
/style.css
/js/
  storage.js       تخزين localStorage منظم
  questions.js      التصنيفات + بنك أسئلة Demo
  scoring.js        احتساب النقاط والمكافآت وXP
  ai-service.js      الاتصال بنموذج الذكاء الاصطناعي (Puter أو Gemini) + التحقق من JSON
  ui.js             تنقل الشاشات، التنبيهات، الأصوات
  game.js           تحكم اللعب الفردي (صعوبة تكيفية، مؤقت، نتائج)
  multiplayer.js     عميل WebSocket للعب الجماعي وOnline 1v1
  settings.js        شاشة الإعدادات
  app.js            نقطة الدخول وربط كل شيء
/server             خادم Node.js حقيقي (WebSocket + HTTP) — راجع server/README.md
  server.js
  rooms.js
  questions.js
  leaderboard.js
  data/leaderboard.json
```

## التشغيل

هذا مشروع Static بالكامل — يكفي فتح `index.html` في المتصفح، أو تقديمه عبر
أي خادم ملفات ثابتة (مثل `npx serve` أو GitHub Pages). أضف الـ API Key من
شاشة الإعدادات لتفعيل الأسئلة التي ينشئها الذكاء الاصطناعي.
