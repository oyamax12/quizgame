# فيصل — لعبة الأسئلة الذكية

لعبة تريفيا تعتمد على الذكاء الاصطناعي، مبنية بـ HTML5 + CSS3 + JavaScript ES6+ فقط
(بدون React/Vue/Angular/TypeScript)، بواجهة عربية RTL وتصميم متجاوب Mobile First.

## ما تم بناؤه في هذه المرحلة (المرحلة 1 + المرحلة 2 كاملتين، وأجزاء من 3 و4)

- الصفحة الرئيسية + التنقل بين الشاشات.
- الإعدادات: حفظ/مسح API Key (مموّه بعد الحفظ)، اختيار/كتابة اسم Model، زر
  اختبار الاتصال، شارة حالة الاتصال 🟢🔴🟡، إعدادات اللعبة العامة، الوضع الداكن/الفاتح، الصوت.
- **Demo Mode** تلقائي عند غياب الـ API Key، ببنك أسئلة محلي.
- لعب فردي كامل: اختيار تصنيف/صعوبة (أو تلقائي)/عدد أسئلة/مدة السؤال، توليد
  الأسئلة عبر `AIService` (متوافق حاليًا مع نماذج Gemini، وقابل للتوسّع)،
  التحقق من صحة JSON وإعادة المحاولة تلقائيًا عند الفشل، مؤقت لكل سؤال،
  نظام نقاط مع مكافأة سرعة وسلسلة (Streak) وأنواع جولات (عادية/سريعة/مضاعفة/أخيرة)،
  Power-Ups أساسية (50/50، تجميد الوقت، تغيير السؤال)، وضع Chaos/Madness،
  شاشة نتائج مع XP والمستوى والإنجازات، وملف شخصي بالإحصائيات والإنجازات.
- تخزين كل شيء في `localStorage` ضمن كائنات JSON منظمة — لا يوجد أي API Key
  مكتوب داخل الكود.

## المراحل المتبقية (5 و6) — Multiplayer وOnline 1v1

الأزرار الخاصة بها موجودة في الواجهة (معلّمة بـ"قريبًا") ولا تكسر شيئًا من
اللعب الفردي. لإكمالها لاحقًا:

1. أنشئ خادم Node.js داخل `/server` يستخدم WebSocket أو Socket.IO لإدارة:
   الغرف (إنشاء/انضمام برمز)، حالة اللاعبين (جاهز/غير جاهز)، مزامنة الأسئلة،
   واحتساب النقاط والوقت **على الخادم حصرًا** لمنع الغش.
2. استبدل محتوى `js/multiplayer.js` باتصال فعلي بالخادم، مع الحفاظ على نفس
   الواجهة العامة حتى لا يتأثر بقية الكود.
3. لا ترسل `correctAnswer` إلى المتصفح قبل إغلاق وقت الإجابة في أوضاع
   Multiplayer وOnline 1v1.
4. أضف قاعدة بيانات (مثلاً PostgreSQL أو MongoDB) لحفظ المستخدمين، الغرف،
   والمتصدرين العالميين — لا تعتمد على `localStorage` لهذه البيانات.

## ملاحظة أمان مهمة

هذا الإصدار يتصل بالـ AI API مباشرة من المتصفح (`Frontend → AI API`)، وهو
مناسب للاستخدام **الشخصي** فقط لأن أي شخص يفتح أدوات المطوّر يرى المفتاح.
عند النشر للعموم، أضف خادمًا وسيطًا (`Frontend → Backend → AI API`) بحيث
يبقى الـ API Key على الخادم فقط. طبقة `AIService` مصممة بحيث لا يحتاج بقية
الكود لأي تعديل عند إجراء هذا الانتقال — فقط عدّل دالة `callModel()`.

## هيكل الملفات

```
/index.html
/style.css
/js/
  storage.js       تخزين localStorage منظم
  questions.js      التصنيفات + بنك أسئلة Demo
  scoring.js        احتساب النقاط والمكافآت وXP
  ai-service.js      الاتصال بنموذج الذكاء الاصطناعي + التحقق من JSON
  ui.js             تنقل الشاشات، التنبيهات، الأصوات
  game.js           تحكم اللعب الفردي (صعوبة تكيفية، مؤقت، نتائج)
  multiplayer.js     محجوز للمراحل القادمة
  settings.js        شاشة الإعدادات
  app.js            نقطة الدخول وربط كل شيء
/server             (فارغ حاليًا — للمرحلتين 5 و6)
```

## التشغيل

هذا مشروع Static بالكامل — يكفي فتح `index.html` في المتصفح، أو تقديمه عبر
أي خادم ملفات ثابتة (مثل `npx serve` أو GitHub Pages). أضف الـ API Key من
شاشة الإعدادات لتفعيل الأسئلة التي ينشئها الذكاء الاصطناعي.
